# glamis-guide-data

The offline imagery of the [Glamis Guide](https://glamisguide.app) app as
map tiles for Gaia GPS custom map sources and any other app that takes a
tile URL. Generated; nothing here is edited by hand.

- `10/` to `16/`: the offline NAIP imagery as XYZ JPEG tiles, served by
  GitHub Pages at `https://tiles.glamisguide.app/{z}/{x}/{y}.jpg` for Gaia GPS custom map sources and any
  app that takes a tile URL.
- Imagery: USDA NAIP via USGS The National Map, public domain, graded by
  Glamis Guide.
